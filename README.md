# SpiritVale 繁體中文化外掛

給 **SpiritVale(靈谷)** 的繁體中文即時翻譯外掛,附圖形化設定工具與一鍵診斷。

> 即時翻譯層:進遊戲後英文自動換成繁中(含伺服器送來的文字)。
> **不修改任何遊戲檔案**;線上遊戲使用外掛有其風險,請自行斟酌。

## 安裝

1. 解壓縮 ZIP(**不要**解在遊戲資料夾裡)
2. 執行 **`安裝.bat`**,照畫面指示選顯示模式與字型
3. 用 Steam 正常啟動遊戲

首次啟動會出現黑色載入視窗跑進度(1~3 分鐘,之後只要數秒),**跑完會自動消失,請不要關掉它**。

安裝後想改設定:雙擊 **`設定工具.bat`** —— 圖形介面直接調,不用重裝,多數設定遊戲開著也能即時生效。

## 功能一覽

**翻譯**
- 四種顯示模式:全部雙語 / 物品名雙語 / 物品名純中文 / 原文
- 自訂翻譯與保留原文清單(自己的說法優先於內建字典)
- 中文搜尋反查:背包/市場搜尋框打中文也找得到
- 自訂字型(可從系統已安裝字型挑,附即時預覽)

**遊戲體驗**(公會專用版)
- 掉寶音效:依光柱顏色分別設定音效與音量,可依分類/稀有度/指定物品過濾
- 掉落光柱:自訂顏色、RGB 循環、放大、隱藏不想看的分類
- DPS 傷害統計面板:自身 / 隊伍 / 全部 / 王 四種模式,可拖曳
- 詞條品質:背包物品依 roll 值標色,支援「品質90」這類搜尋
- 市場工具:查市價(含離線紀錄)、市場分析、面板位移
- 狀態圖示(Buff/Debuff)自訂位置:可拖曳的面板,或跟著角色自動排版
- 王技提示音、王方位箭頭、自訂滑鼠游標、地圖背景音樂

**支援**
- 一鍵診斷:產生報告(系統環境、檔案完整性、設定值、關鍵 log),回報問題時附上它就好

## 回報問題

請附上下列**其中一項**:

- 跑 **`一鍵診斷.bat`** 產生的 `SpiritZh_診斷報告.txt`(推薦,資訊最完整)
- 或遊戲資料夾裡的 `BepInEx\LogOutput.log`

外加一句話說明「你做了什麼 → 期待看到什麼 → 實際看到什麼」,加上截圖最好。

## 常見問題

**Q:安裝完進遊戲還是英文?**
先跑一鍵診斷。最常見原因是防毒軟體把外掛檔案吃掉了 —— 報告的「外掛檔案」區段會直接標出缺哪個檔。

**Q:更新後設定不見了?**
不會。安裝程式會保留你原本的設定檔,更新完自動還原,新增的選項會補進去。

**Q:遊戲更新後外掛失效?**
遊戲改版後外掛需要重新產生相容檔案,通常重開一次遊戲就好;若出現紅字請重跑安裝。
