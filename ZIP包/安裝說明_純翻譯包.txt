SpiritVale 繁體中文翻譯 — 一鍵安裝包(ZIP 版)
================================================

※ 這是純翻譯包。公會專用版另有隱藏玩家、掉落音效、光柱、品質快篩、DPS 等功能,
  僅供 Electronic Sheep 公會成員使用。

■ 安裝(全部操作都在「設定工具.bat」)
------------------------------------------
1. 把整個 ZIP 解壓縮到任意資料夾(不要在壓縮軟體裡直接執行)
2. 雙擊「設定工具.bat」→ 選好顯示模式與字型 → 按「安裝 / 更新翻譯」
3. 顯示模式說明:
   [1] 全部雙語      所有遊戲名詞都「中文 English」——物品、技能、職業、
                     屬性、狀態、NPC、地圖、怪物。適合對照英文攻略。
                     例:水龍卡片 Aqua Drake Card / 風車斬 Whirlwind
   [2] 物品名雙語    只有物品名雙語,技能等其他名詞純中文(預設)
                     例:水龍卡片 Aqua Drake Card / 風車斬
   [3] 物品名純中文  物品名也只顯示中文,畫面最乾淨
                     例:水龍卡片 / 風車斬
   [4] 原文          完全不翻譯,保持英文介面——想暫時切回英文介面、
                     又不想整個移除翻譯時用
   ※模式 1/2 的地圖名與怪物名會雙語(隊伍搜尋要打英文,方便對照);
     模式 3 徹底全中文。技能敘述等「句子」任何模式都純中文;
     市場都能打中文搜尋。純中文模式要搜隊伍時,可暫時切模式 2
     看位置英文(約 5 秒生效),搜完再切回來。
   ※裝完後想換模式/字型:開設定工具改完按「套用」即可,不用重裝。
4. 用 Steam 正常啟動遊戲

■ 首次啟動注意
------------------------------------------
‧首次啟動(以及每次遊戲改版後的第一次)會出現黑色載入視窗,
  花約 1~3 分鐘產生外掛需要的組件——請耐心等它跑完、不要關閉它,
  跑完會自動消失。之後每次啟動只需幾秒。
  (安裝時加了防毒排除,這個生成過程就不會被 Defender 干擾。)
‧首次啟動若伺服器列表是空的(連線逾時),重開一次遊戲即可

■ 關於「系統管理員授權(UAC)」
------------------------------------------
安裝過程『可能』會跳出一次 UAC 授權視窗,用途『僅為』把遊戲資料夾加入
Windows Defender 的排除清單——這樣『遊戲每次更新後』外掛需要重新
產生的組件才不會被防毒誤刪(那會造成紅字錯誤)。
本安裝不連網、不蒐集資料,腳本皆為明文可自行檢視。若你不想授權,
按「否」即可,安裝仍會完成。

★ 沒看到 UAC 視窗是正常的,不代表安裝失敗。以下情況本來就不會跳:
  ‧遊戲資料夾『已經在』排除清單裡(例如你以前裝過)→ 不需要再加,直接略過
  ‧你用的是『第三方防毒』(非 Windows Defender)→ 讀不到 Defender 設定,略過
  ‧系統的 UAC 設定為『不通知』→ 系統自己允許,不會顯示視窗
  ‧遊戲『不在』C:\Program Files 這類受保護位置 → 複製檔案本來就不需要提權

  安裝結束時只要看到「安裝完成」,而且遊戲進去有中文,就是成功了。
  想確認防毒排除有沒有加到,可執行 diagnose.ps1 看報告。

■ 疑難排解
------------------------------------------
‧跳出小視窗「Failed to start BepInEx」:
  代表外掛的執行環境被擋住了,依序試:
  1) 確認安裝時的 UAC 授權有按「是」(加防毒排除);沒有的話設定工具
     重按「安裝 / 更新翻譯」並允許——會在複製前先加排除,並自動解除
     檔案的「網路下載封鎖標記」。
  2) 安裝微軟的 Visual C++ 執行階段(很多遊戲共用,裝一次就好):
     https://aka.ms/vs/17/release/vc_redist.x64.exe
     ※若安裝時跳出「0x80070666 已安裝這個產品的其他版本」,
       代表你電腦裡已經有更新的版本了 —— 這是正常的,直接按關閉、
       跳過這一步即可,不用理會,也不需要去移除重裝。
  3) 若解壓縮前沒解封鎖:在下載的 zip 上按右鍵 → 內容 →
     勾選「解除封鎖」→ 確定 → 重新解壓縮 → 重跑安裝。
‧Chrome 下載時顯示「已封鎖」「不安全」:
  這是瀏覽器對「少見的未簽章壓縮檔」的預設攔截,不代表檔案有毒。
  點下載列該項目右邊的「…」(或 ∨)→「保留」→「仍要保留」即可。
  下載後可以到 VirusTotal 網站上傳檔案自行驗證,或核對發文底部的 SHA256。
‧遊戲啟動時黑窗出現「應用程式控制原則已封鎖此檔案 (0x800711C7)」:
  這【不是防毒、也不是防火牆】,是 Windows 11 的「智慧型應用程式控制」
  (Smart App Control)。它會封鎖沒有數位簽章的程式碼,而本外掛每次啟動
  產生的組件正是沒有簽章的,所以會被擋。
  重點:它和防毒是兩套獨立系統,【加防毒排除不會讓它放行】。
  唯一解法是關閉它:
    Windows 安全性 → 應用程式與瀏覽器控制 → 智慧型應用程式控制設定 → 關閉
  ※但請先知道:智慧型應用程式控制一旦關閉就【無法再開啟】,要恢復必須
    重灌 Windows(這是微軟的設計)。關閉後電腦也就少了這層防護。
  這是你自己的取捨 —— 若你不願意關,那就無法使用本外掛,這完全合理。
  (設定工具「產生診斷報告」可以直接看出你這台是不是開著。)
‧黑窗出現紅字「Could not load file or assembly ...」:
  這是防毒(Defender)把外掛要重新產生的組件刪掉了(常見於遊戲剛更新後)。
  解法:確認安裝時的 UAC 授權有按「是」;若當時按了「否」,重跑
  設定工具「安裝 / 更新翻譯」並允許授權。仍不行的話,手動加排除:
  Windows 安全性 → 病毒與威脅防護 → 管理設定 → 排除項目 →
  新增排除項目 → 資料夾 → 選遊戲資料夾。加完重開遊戲即可。
‧黑窗跑完遊戲卻沒出現/按了沒反應:
  多半是缺「Visual C++ 執行階段」,安裝微軟官方套件後重試:
  https://aka.ms/vs/17/release/vc_redist.x64.exe
‧上述都無效:設定工具按「產生診斷報告」——它會檢查系統、遊戲位置、每個
  外掛檔案是否存在或被封鎖、防毒排除、VC++ 版本、以及 BepInEx 日誌,
  然後在【桌面】產生「SpiritZh_診斷報告.txt」。把這個檔案貼給作者,
  就不用來回猜問題出在哪了。(只讀取資訊,不會修改任何東西,
  報告也不含個人資料。)
‧或用設定工具「移除翻譯」→「安裝 / 更新翻譯」重裝一次

■ 設定工具功能一覽
------------------------------------------
純翻譯包的設定工具只有「安裝 / 翻譯與字型 / 自訂 / 關於」四個分頁。
‧顯示模式三選一——改完約 5 秒自動生效,遊戲開著也行
‧中文字型下拉選單——列出你電腦「全部」已安裝字型(附即時預覽),
  改完在遊戲畫面更新時就換上,不用重開遊戲(只有切回預設字型需要重開);
  想要更多字型:下載安裝到 Windows(右鍵→安裝),重開工具就會出現;
  或用「載入字型檔…」按鈕直接選 ttf/otf 檔——複製進遊戲外掛資料夾就能用,
  不必安裝進系統
‧內建「粉圓體」:字型下拉第一個★選項,不用另外下載(jf-openhuninn,
  justfont 以 SIL OFL 1.1 開源授權,詳見 SpiritZh_fonts\字型授權說明.txt)
‧地圖名上下兩行:「翻譯與字型」分頁的顯示模式區有勾選框,勾了之後雙語地圖名會變成
  「哥布林村莊 ↵ Goblin Village」,不會再從英文中間斷行。
  (3D 傳送石碑的大標籤本來就是兩行,開了會變三行,覺得擋到就取消勾選。)
‧自訂翻譯(「自訂」分頁):把譯文改成你喜歡的說法,例如 HP→生命值、
  物攻→物理攻擊。按「常用範例…」一鍵套上六條屬性縮寫。規則存在
  SpiritZh_custom.txt,更新翻譯包也不會被蓋掉。
‧安裝 / 更新翻譯、產生診斷報告、移除翻譯——都是按鈕,不用再找檔案
‧更新時你調好的顯示模式/字型/自訂翻譯設定都會保留,不會被還原成預設
‧開場動畫:開啟工具時會播放 SpiritVale 開場 LOGO 與音樂,載入完成自動淡出、
  音樂同時停止(不會殘留在背景)。畫面上點一下可立刻跳過。
  最上面那排有「開場動畫」勾選框與「音量」,不想要就取消勾選、
  或把音量設 0(只跑動畫不出聲)。
  想換自己的音樂:檔案改名成 SpiritZh_intro.mp3 放到本工具資料夾即可
  (wav / mp3 / mp4 / m4a 都支援,會蓋掉隨包附帶的那首)
  ※ 隨包的開場音樂 SpiritZh_intro.mp4 由「源」以 Google Gemini 製作,版權歸源所有;
    payload 內另附一首合成備用曲(SpiritZh_intro.wav),兩首都可自由替換
‧不要翻譯的東西:編輯 BepInEx\plugins\SpiritZh_keep.txt,一行貼一個英文原名
  (例:Aqua Drake Card),存檔約 5 秒生效,該名字就會保持英文
‧換了字型沒效果:看 BepInEx\plugins\SpiritZh_status.txt 的「自訂字型」那行
‧以前裝過全功能版(v3.72 以前)的話:它留下的功能設定檔(音效、光柱、品質等)
  會原封不動留在 BepInEx\plugins\,純翻譯包不會去讀、也不會刪,不影響使用

■ 移除
------------------------------------------
設定工具 →「移除翻譯」,遊戲立即恢復原版。
移除時你的設定檔會自動備份到遊戲資料夾的「SpiritZh_設定備份」——之後重裝
把裡面的檔案複製回 BepInEx\plugins\ 即可全部找回;確定不要了直接刪掉那個
資料夾即可。

■ 常見問題
------------------------------------------
‧想換顯示模式/字型:開「設定工具.bat」改完按套用即可(遊戲開著也行)
‧遊戲更新後通常不受影響;若失效,設定工具按一次「安裝 / 更新翻譯」即可
‧回報問題:請附遊戲資料夾內 BepInEx\plugins\SpiritZh_status.txt
  與 SpiritZh_error.log(若存在)
